# Assets de Felices 26, Gema

Sustituye estos archivos sin cambiar sus nombres:

- `gema-face.png`: foto cuadrada de Gema, PNG o JPG convertido a PNG, mínimo recomendado 512 x 512. Mantén la cara centrada y con fondo simple. El juego la recorta con máscara circular.
- `ucam-logo.png`: logo de la UCAM en PNG transparente, con márgenes reducidos y al menos 800 px de ancho si es posible.

Los placeholders actuales solo sirven para que el juego funcione antes de colocar las imágenes definitivas.
